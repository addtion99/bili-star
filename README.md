# B站弹幕净化插件

一个用于过滤 Bilibili 视频弹幕的浏览器扩展，让你在看番时拥有更干净、更舒适的观看体验。

## ✨ 功能特点

插件采用精简弹幕的策略，默认过滤普通弹幕，只保留：

- **特殊弹幕**：保留特殊类型的弹幕。
- **高赞弹幕**：保留获得点赞的弹幕，让有价值的评论得以留下。

通过过滤大量普通弹幕，减少弹幕对观看体验的干扰。

## 🎬 为什么开发这个插件？

看番时，经常会遇到一些影响观看体验的弹幕：

- 剧透后续剧情，影响观感。
- 争吵、引战，破坏观看氛围。
- 对角色戏份、剧情安排进行无意义的争论。

例如，一些关于角色戏份的争吵弹幕，经过插件过滤后，基本不会再出现在屏幕上。

我希望保留真正有意思、有价值的弹幕，同时尽可能减少无意义的信息干扰。
